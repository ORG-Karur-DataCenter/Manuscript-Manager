Enter the dashboard password to start a sync. It is checked by the sync service and held only for this browser session.

The sync runs as a GitHub Actions workflow, so this page needs your permission to start it. Create a fine-grained personal access token for ORG-Karur-DataCenter/Manuscript-Manager with the single permission Actions: Read and write.

You are asked for this once. It is saved in this browser and reused from then on — you will not see this screen again on this device unless GitHub rejects the token or you clear your browsing data. It is sent only to api.github.com, never to this page's server or to anyone else.

Do not use a classic token — those grant far more than this needs.
